# Multi Brand Rivne

Самостійний сайт-каталог магазину Multi Brand Rivne. HTML, CSS і JavaScript; Shopify, збірка та сервер не потрібні.

## Запуск

Відкрийте `index.html` або запустіть `python3 -m http.server 4173` у папці проєкту.

## GitHub Pages

У Settings → Pages виберіть Deploy from a branch, гілку `main` і папку `/ (root)`, потім Save.

## Каталог

Дані містяться в `catalog.js` (використовується сайтом) та `catalog.json`. Під час оновлення змінюйте обидва файли. Фото й шрифти зберігаються поруч із `index.html`.

Ціни й розміри взято з дописів магазину; актуальну наявність необхідно підтверджувати. Добірка зберігається локально в браузері. Сайт допомагає сформувати запит через Instagram, не проводить оплату та не надсилає повідомлення автоматично.
